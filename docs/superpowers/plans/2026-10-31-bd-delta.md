# Import delta BD Oktober (S1–S3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port seluruh kemampuan delta BD Oktober (minus WA/S4 yang diparkir) ke Office Vue: layar Recurring + mesin ulang (S1), reviewers + visibilitas semua-kru (S2), sub-assignee + tag warna + kanban terbaru (S3).

**Architecture:** Fungsi murni (aturan tanggal/seri) di `app/utils/bd-rumus.ts`, penulis ber-`If-Match` di `app/composables/useBd.ts`, UI di halaman/widget yang sudah ada + satu halaman baru `recurring.vue`. Tanpa endpoint API baru kecuali Task 0 membuktikan blob key dibuang server.

**Tech Stack:** Nuxt 4 + Nuxt UI v4 + Tailwind v4 (Vue), Laravel 12 + Pest (bila API tersentuh).

**Spec:** `docs/superpowers/specs/2026-10-31-bd-delta-design.md` (S1–S3; S4 diparkir).

## Global Constraints

- `laksamana-office/` read-only — rujukan saja, tidak diedit.
- Semua tulis Vue lewat `useApi()` + `If-Match` (`versiBaris`) + `tanganiKonflik`; `definePageMeta({ access: ['bd'] })`.
- Blok App* + DESIGN.md; copy UI Indonesia; komentar kode Inggris.
- Tanpa dependensi baru tanpa persetujuan owner.
- Tulis kode saja lawan API lokal/mock; dilarang menyentuh data hidup.
- Tiap task Vue ditutup `npm run lint && npm run typecheck` + cek browser 390px & 1366px terang; tiap task API ditutup `php artisan test tests/Feature/Bd`.

## Review Focus

- Balapan `gulirUlang` dua tab → seri kembar. Wajar: tab kedua kalah `If-Match`/409 lalu muat ulang. Diuji: Task 2 (buka dua tab, majukan seri, pastikan satu seri penerus).
- Tanggal ujung (`bulanan_ke` hari ke-5, 31 Jan → Feb, 29 Feb). Wajar: ikut `langkahUlang` lama (clamp + lompat). Diuji: Task 1 (kasus 31 Jan, Selasa ke-5, 29 Feb).
- Reviewer-only tak terlihat di My Task. Wajar: selalu masuk seksi teratas. Diuji: Task 4 (user reviewer-bukan-pelaksana).
- Warna tag bentrok/tak terbaca. Wajar: palet 12 + hindari duplikat + hash stabil. Diuji: Task 6 (buat 13 tag, cek unik; kontras di terang).
- Hentikan seri menghapus pola. Wajar: pola tersimpan di `ulangBerhenti.u`, head tetap ada. Diuji: Task 2 (henti → lanjutkan tanpa input pola).
